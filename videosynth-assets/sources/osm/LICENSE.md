# OpenStreetMap extract

`bradford_on_avon.json` is an extract of OpenStreetMap data covering
Bradford-on-Avon, Wiltshire, United Kingdom, fetched from the Overpass API by
[`scripts/fetch_osm_extract.sh`](../../scripts/fetch_osm_extract.sh) and
trimmed to the tags the map renderer reads. The data's OSM timestamp is in the
file's `timestamp_osm_base` field.
